# Capri

Capri — конструкт *Project Capricorn* из *Cyberpunk: Edgerunners*. Она живёт на рабочем столе и показывает, чем заняты помощники для программирования: Claude Code, Codex и Antigravity. Она телепортируется, реагирует на задачи, зовёт вас, когда нужно разрешение, и празднует завершение работы.

![Capri сообщает о завершении задачи](docs/done.png)

## Возможности

- Отслеживание событий Claude Code, Codex, Antigravity и OpenCode через соответствующие интеграции.
- Отображение действий, запросов разрешения, ошибок и итогов прямо на рабочем столе.
- Общение текстом и голосом. Голос распознаётся локально на компьютере с помощью Whisper.
- Поиск в интернете, поиск по заметкам Obsidian и управление отдельным окном Brave.
- Необязательные анимации, звуки и визуальные комментарии к игре.

## Быстрая установка — Windows

1. Скачайте последнюю версию установщика на странице [Releases](https://github.com/mochiiwuff/capri-desktop/releases).
2. Установите и запустите Capri.
3. Выберите интеграцию в меню персонажа и перезапустите помощник по программированию, чтобы загрузить hooks.
4. Чтобы общаться с Capri, выберите модель в меню **AI model**. Для облачных провайдеров нужен API-ключ; Ollama работает локально.

## Запуск из исходного кода

Требуется Node.js версии 20 или новее.

```bash
git clone https://github.com/mochiiwuff/capri-desktop.git
cd capri-desktop
npm install
npm run dev
```

Чтобы собрать установщик Windows, выполните `npm run dist`. Демонстрацию без подключения помощника запускает `npm run demo`.

## Голос, экран и конфиденциальность

- Голос распознаётся на этом компьютере с помощью Whisper; аудио не отправляется в облачный сервис распознавания речи.
- Передача снимков экрана облачной модели требует отдельного разрешения и по умолчанию отключена.
- Комментарии к игре необязательны и по умолчанию выключены.
- Интеграция Brave использует локальное расширение. Содержимое страниц и результаты поиска считаются недоверенными данными.
- Подробнее о передаваемых данных: [Что покидает ваш компьютер](README.md#what-leaves-your-machine).

## Тесты и разработка

```bash
npm test
npm run test:voice
npm run test:browser
npm run test:evolution
```

Отслеживание окон работает только в Windows. В macOS и Linux Capri продолжает парить и анимироваться на рабочем столе.
